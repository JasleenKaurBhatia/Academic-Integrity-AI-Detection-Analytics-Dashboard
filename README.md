# Academic-Integrity-AI-Detection-Analytics-Dashboard
•	Built an interactive Power BI dashboard using Power Query, DAX, data modelling, and interactive visualizations to analyze academic integrity patterns.
•	Identified student cheating networks and AI-detection patterns through similarity scores, network relationships, and detection metrics.
•	Enabled faster identification of potential academic-integrity cases by consolidating student-level, similarity, and AI-detection insights into a single dashboard.
